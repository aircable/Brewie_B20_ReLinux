First, download an updated image from:
http://images.olimex.com/release/a13/
I used the A13-OLinuXino-focal-minimal.
Unzip, and flash to the sd-card.
put it in the machine, and boot. 

You will need to have an usb-serial interface connected to the four pins on the A13SOM board, in order to setup the wifi etc. (or if you know your way around linux, you might be able to set it up before the first boot, by editing the image).
I use the program "putty" to connect (both through serial, and through wifi after it has been set up). 
login/password is: olimex/olimex

The easiest way to set up wifi, is to run:
sudo nmtui
After doing that, I prefer connecting through wifi - again, using putty.

The screen is actually working at this point, but the backlight is initually turned off.
Turn it on by running the following three commands:

sudo echo 35 > /sys/class/gpio/export
sudo echo out > /sys/class/gpio/gpio35/direction
sudo echo 5 > /sys/class/gpio/gpio35/value

I haven't yet been able to do this more effeciently - I would have prefered it, if it could be done in the dts overlay, so it was enabled during uboot, but I haven't figured out how to do that yet.

After having connected to wifi, update the system:
sudo apt-get update
sudo pat-get upgrade

I usually install my favourite command line editor "mc":
sudo apt-get install mc

Run the following command to expand the file-system to fill the whole sd-card:
sudo resize2fs /dev/mmcblk0p1


Next, to enable the touch panel functionality, we need to make a dts overlay file.
I have added it to this zip file: touch.dts.
To me, the easiest way to do this, is to open the file in notepad, copy all the text( ctrl + a, ctrl + c). Then create a new file in your home directory:
nano touch.dts
then paste in the text you copied, simply by right-clicking.
Save the file: (ctrl + o), and exit: (ctrl + x).
Now the file needs to be converted from dts to dtb:
sudo dtc -I dts -O dtb -o /boot/touch.dtb touch.dts

last, add it to the boot envirenment - open uEnv.txt in the /boot directory - I use mc:
sudo mc
(navigate to /boot, and open uEnv.txt for editing, using F4)
at the bottom the line should read:
fdtoverlays= /boot/touch.dtb

You can rotate the screen by adding adding the line:
optargs=fbcon=rotate:X
where X is a number. Set it to 2 to flip it 180 degrees, or if you want the text to follow the way the screen is oriented in the brewie, you would use the line:
optargs=fbcon=rotate:1

This should provide a basic minimal system, with access to the apt package manager and some other stuff.

NOTICE: It seems that the touch panel can use two different addresses - either 0x14 or 0x5d.
I'm unsure how and why it might change this address. For me it has worked well with 0x14, but if you're having trouble, you can try the other one.
